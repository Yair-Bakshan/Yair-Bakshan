## About

I'm a student from Israel. I want to understand how computers work at the lowest level:
how a PC boots, how the CPU runs code, and how programs can be analyzed and broken.

- **Low-level programming:** C and x86 Assembly
- **Pwn / Binary exploitation:** learning through CTF challenges
- **Reverse engineering:** reading binaries with IDA and GDB

## Featured Projects

### [32bit-bootloader](https://github.com/Yair-Bakshan/32bit-bootloader)

x86 bootloader written from scratch. It starts in 16-bit real mode, loads a C kernel from disk, and switches the CPU to 32-bit protected mode.
